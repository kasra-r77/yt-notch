# Security

Please don't report a security problem in a public issue.

Report it privately instead: on this repository's **Security** tab, choose **Report a vulnerability**. Only the maintainer sees the report. You'll get a reply within a week, and credit in the fix if you'd like it.

Useful things to include: what the problem is, how to reproduce it, which version of YT Notch (menu bar icon › Copy Diagnostics has it), and what someone could do with it.

YT Notch keeps very little: the window's size, its settings, a list of your playlist names to show before the site loads, and the site's own sign-in in its web storage. It never sees your password, and its log holds no account data.
